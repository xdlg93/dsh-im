## 一键更新不再被 github.com 卡住

从插件索引安装会让 `pnpm` 直接 `git clone github.com`，这一步不经过 npm 源、也不吃 npm 的代理配置；国内直连会 `Recv failure: Connection was reset`。1.3.1 给了代理说明和 tgz 直链安装，但**一键更新仍然只走 git**。1.3.2 把这条路补齐了。

### 新增

- **索引里每个版本多带一个 `tgz` 直链**（`https://xdlg93.github.io/dsh-im/pkg/dsh-im-<版本>.tgz`）。这是 format 1 的非标准字段，市场解析器会忽略，只有本插件的更新器读取。
- **更新器按当前安装方式选通道**：
  - 从 tgz 安装的 → 直接用 tgz，不做无效的 git 尝试；
  - 从 git 安装的 → 先试 git，**失败后自动改用同版本 tgz**；
  - 只有网络类失败（`install-failed` / `install-timeout`）才换通道，版本或状态问题仍然直接报错，不用 tgz 掩盖。
- **面板显示安装方式**：新增「安装方式」（git / tgz 直链）一行，「更新来源」标注为「插件索引（git + tgz 兜底）」；切换通道时提示「git 不可达，本次已改用 tgz 直链安装」。
- `installChannelOf()` 把 profile 依赖归类为 registry / git / tgz / local，**只有 local（link/file/workspace）仍禁止自动更新**。

### 安装 / 更新

```bash
# 从索引或 git（需要能访问 github.com，或按 README 配好代理）
dsh plugin --profile web add git+https://github.com/xdlg93/dsh-im.git#v1.3.2

# 完全不碰 github.com
dsh plugin --profile web add https://xdlg93.github.io/dsh-im/pkg/dsh-im-1.3.2.tgz
```

插件索引：`https://xdlg93.github.io/dsh-im/index.json`
