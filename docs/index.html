dsh-im 插件索引

这是 DeepSeek Harness 的插件市场索引，只包含微信与 QQ 两个扫码通道。

在 DSH 里添加索引

设置 → 插件 → 发现 → 添加索引源，粘贴下面这个地址：

https://xdlg93.github.io/dsh-im/index.json

直接安装

dsh plugin --profile web add git+https://github.com/xdlg93/dsh-im.git

访问不了 github.com？

从索引安装会让 pnpm 直接 git clone github.com，这一步不走 npm 代理。可以改用同版本的安装包：

dsh plugin --profile web add https://xdlg93.github.io/dsh-im/pkg/dsh-im-1.3.1.tgz

或者给 DSH 进程设置 HTTPS_PROXY，或执行 git config --global http.proxy <代理>。
