# 命令说明

[English](bot-commands.md) · [返回 README](../README.md)

机器人在微信与 QQ 里都接受以 `/` 开头的命令。命令只识别纯文字消息，沿用当前机器人的访问策略与命令权限，任务运行期间也可以及时响应；命令不会触发新的模型调用，除非它本身需要提交任务。

## 权限档位（QQ）

`/permission` 查看当前绑定会话的权限；`/permissionlist` 按序号列出 Host 当前可用档位并标记当前项。先发 `/permissionlist`，再发 `/permission 2`；也可直接发 `/permission workspace-write`，纯数字 ID 使用 `/permission id:123`。序号来自当前机器人、当前聊天最近一次列表，有效期 15 分钟，机器人重启后失效；切换绑定会话后需重新列出。切换直接作用于当前 Session，同时按 Host 定义更新沙箱和审批策略，不修改新会话默认值；已经执行的工具和待处理审批不会重放或自动获批。档位以 Host 实际提供的目录为准，`custom` 仅表示当前状态，不能选择。

微信当前没有该命令。

## 会话

| 命令 | 说明 |
| --- | --- |
| `/new [标题]` | 解除当前聊天的会话绑定，让下一条普通消息开启全新 Harness 会话；可带标题。 |
| `/reset` | 重置当前会话上下文，保留会话编号，旧会话仍可用 `/session` 找回。 |
| `/clear` | 清空当前会话上下文，保留 Session 绑定和历史记录。 |
| `/compact` | 立即压缩当前会话的较早上下文。 |
| `/sessionlist`、`/sessions` | 列出当前工作区的会话 ID 与标题，并标出本对话已绑定的会话。`--all` 跨工作区汇总，`--limit N` 限制条数。 |
| `/session <Session ID、序号或标题关键词>` | 把当前聊天绑定到已有会话；标题关键词只在当前工作区唯一命中时自动绑定。 |
| `/history [数量]` | 在私聊中查看当前绑定会话的最近消息，默认 3 条，最多 5 条。 |
| `/status` | 查看机器人与 Harness 的连接状态、实际工作区、绑定会话、当前模型与 Agent Preset。 |
| `/version` | 查看当前运行的插件版本。 |

`/status` 不会向模型发送消息，也不会改变会话绑定；整条回执始终是一条消息，某个字段暂时读不到时只省略该行。

## 工作区与模型

| 命令 | 说明 |
| --- | --- |
| `/workspace`、`/ws` | 不带参数时列出可切换的工作区；带序号或绝对路径时直接切换。 |
| `/conv`、`/conversation` | 查看或设置当前对话的专属工作区；`/conv clear` 清除。 |
| `/models` | 按序号列出当前配置的全部可用模型。 |
| `/model` | 查看当前会话正在使用的模型和推理等级。 |
| `/model <序号或 Provider/模型ID> [推理等级ID]` | 切换当前会话模型，可同时指定目标模型支持的推理等级。 |
| `/reasoninglist`、`/reasonings` | 列出当前模型支持的推理等级。 |
| `/reasoning` | 查看当前会话的模型和推理等级。 |
| `/reasoning <序号或等级ID>` | 切换当前模型的推理等级。 |
| `/reasoning --default` | 恢复当前模型的默认推理等级。 |

模型与推理等级的切换只影响当前会话；机器人卡片里的模型设置只影响之后新建的会话。

## Agent Preset

| 命令 | 说明 |
| --- | --- |
| `/presetlist`、`/presets` | 按序号列出 Host 当前可用的 Agent Preset，并标记 Host 默认项和当前机器人的选择。 |
| `/preset` | 查看当前机器人的新会话 Agent Preset 设置。 |
| `/preset <序号或 Preset ID>` | 设置当前机器人的 Agent Preset；纯数字 ID 使用 `/preset id:<ID>`。 |
| `/preset --default` | 清除显式选择，让后续新 Session 跟随 Host 默认。 |

## 任务控制

| 命令 | 说明 |
| --- | --- |
| `/stop` | 立即停止当前聊天正在运行的任务，并保留尚未开始的排队消息。 |
| `/steer <补充指令>` | 把补充指令立即加入当前聊天正在运行的任务。 |
| `/batch` | 在私聊中开启批量输入，最多收集 10 条纯文字消息。 |
| `/send` | 把已收集的消息按原顺序作为一次输入提交。 |
| `/cancel` | 取消批量输入并丢弃已收集的消息。 |

如果机器人的「任务运行时的新消息处理方式」设为插话，普通纯文字消息会自动加入当前任务，无需每次输入 `/steer`。

## QQ 菜单

`/menu` 或 `/m` 打开按钮与数字菜单：会话选择、工作区、模式／预设、模型、新会话、会话列表、停止、压缩、补充指令、归档显示切换、状态和帮助。列表支持分页；按钮不可用时直接回复数字选择。菜单按聊天和操作者隔离，15 分钟或机器人重启后失效；发送普通消息会退出数字选择，审批、提问和批量输入保留原有优先级。

## 交互式提问与审批

- **交互式提问**：回复选项序号、选项文字或自定义文字；多选时用逗号分隔。
- **远程审批**：回复「批准」「拒绝」「同意」「不同意」「yes」「no」。Web 与机器人可同时处理同一审批，先提交的「批准一次」或「拒绝」生效，另一端随即失效；不提供永久批准。

## 帮助

`/help` 显示机器人支持的命令和用法。命令的可用范围受当前机器人的访问策略和命令权限限制：没有权限时命令会被拒绝，而不是静默忽略。
